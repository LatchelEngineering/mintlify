# Documentation Updates

<Info>
  ## Major Updates/Training

  <Accordion title="Replies on PM-Managed Work Orders + New “Review for Emergency” Task">
    **Why it matters:**<br />When a PM manages a work order, the PM owns the conversation with the resident and SP. Ops stepping into those threads creates duplicate or conflicting replies.

    **What changed:**<br />Engineering released a routing change. On work orders **Managed by PM**, Conversation notifications now go **only to the PM**. Ops won't be notified anymore, even if you replied in the thread earlier. If a resident's reply is flagged as a potential PD/EH, the system creates a **"Review for emergency"** task for the Troubleshooting team. The WO itself isn't changed: severity stays the same and it isn't moved to Troubleshooting.

    **What you need to do:**

    1. **All associates:** check **Managed by** before you claim a Conversation. If it says PM, don't claim it or reply to the resident or SP.
    2. **All associates:** leave it with the PM. Possible emergencies come to Troubleshooters as a task.
    3. **All associates:** if you still get notified on a PM-managed thread, submit a bug report.
    4. **Troubleshooters:** on a "Review for emergency" task, review the Conversation, the PM's Intake Settings and the WO notes. Call the resident if it could be an emergency.
    5. **Troubleshooters:** update severity only once the emergency is confirmed, then follow the path for why the WO is Managed by PM (keep it PM-managed and call the escalation contacts, or **Switch to Latchel** if it was de-escalated as stale). Not an emergency? Leave a note and follow the PM's subscription path.

    **When it takes effect:**<br />Effective immediately (11/03/2026)

    **Resources impacted:**

    - [Job Aid: Handling AI Messaging – Conversations](https://help.latchel.com/latchel-admin/Service-Operations/Production-Documentation/Job-Aid-Handling-Resident-and-SP-Conversations-AI-Messaging-Beta)
    - [How to: Handle Emergency Work Orders](https://help.latchel.com/latchel-admin/Service-Operations/Production-Documentation/How-to-Handle-Emergency-Work-Orders): See the "Review for Emergency" Tasks (from Conversations) section.
  </Accordion>
</Info>
