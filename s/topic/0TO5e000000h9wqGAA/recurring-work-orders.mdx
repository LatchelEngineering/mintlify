title: "Recurring Work Orders"

As a Property Manager, you often deal with maintenance tasks that need to happen on a schedule—think weekly pool cleaning, quarterly inspections, or monthly common area upkeep. Recurring Work Orders take those repetitive, manual tasks off your plate by automating the work order creation process, and you can now **create and manage them yourself, directly in Latchel**.

Our goal is simple: give you an easy way to set up scheduled maintenance for single units or entire buildings/common areas right from your dashboard, and have Latchel automatically handle the ongoing scheduling. This guide will walk you through what the service is and how it benefits you and your properties.

### **What is Recurring Work Order?**

A **Recurring Work Order** is a maintenance task that is scheduled to **repeat automatically** (e.g., weekly, monthly, quarterly) in Latchel.

It can be setup for:

- A **single unit** (e.g., annual HVAC filter change).
- A **whole building or Common Area** (e.g., hallways, pool, shared laundry, landscaping, etc.).

### **Key Benefits of this Service**

1. **Time Savings and Reduced Manual Work**

Once a recurring work order is set up, you no longer need to manually create the same maintenance ticket every week, month, or quarter. Latchel creates each work order in the series based on the frequency, start date, and optional end date you choose.

2. **Reliable, Consistent Maintenance**

Recurring tasks like landscaping, pool cleaning, or common area checks happen reliably on schedule, minimizing the risk of missed tasks and preventing minor issues from escalating into major repairs.

3. **Full Control, Right in Latchel**

Set up a recurring work order from the **Maintenance** tab, turn any existing work order into a recurring one, or repeat a new work order on a schedule as you create it. You can assign the same service provider to every work order in the series, choose whether we coordinate with the resident, and pause or resume a series anytime.

4. **Better Property Data through Organized Portfolios**

If a building's common area hasn't been set up as a separate property in Latchel yet, our team will create it and associate it correctly, keeping your portfolio organized and improving accuracy for reporting and tracking. To request a common area property for recurring work, contact [opsintegrations@latchel.com](mailto:opsintegrations@latchel.com).

### **Common area properties for non-recurring work orders**

<Note>
  For non-recurring work orders—meaning single work orders that won't be created on a regular basis—please contact your CSM to submit the properties where you want to create common areas. Note that common area properties set up through this process will only be used for non-recurring (one-time) work orders.
</Note>
