<Note>
  This guide is for property managers and admins. Residents submit requests through their own flow and still go through the diagnostic questions. Share [Submitting a New Maintenance Request (Resident)](/s/topic/0TO5e000000h9wrGAA/How-can-a-Resident-Submit-a-Maintenance-Request) with them instead.
</Note>

Need to get a repair moving? You can create a work order for any of your properties right from your Latchel dashboard. Add the details you already know, choose a service provider if you have one in mind, and Latchel takes it from there.

<Check>
  **In other words:**

  Pick the property and resident, fill in what the job needs, review it, and submit. Latchel starts working on the work order as soon as you do.
</Check>

### **How to Submit a New Work Order**

<Steps>
  <Step title="Start a new work order." icon="1" iconType="sharp-solid" stepNumber={1} titleSize="h4">
    Log in to your [Latchel dashboard](https://app.latchel.com/login) and start a work order in either of these two ways. Both open the same form.

    - Click **+New Work Order** on your dashboard.

    <Frame>
      ![The +New Work Order button on the Latchel dashboard](/images/rtaImage-312.jpg "The +New Work Order button on the Latchel dashboard")
    </Frame>

    - Or open the **Maintenance** dropdown, select **Work Orders**, and click **Create Work Order**.

    <Frame>
      ![The Create Work Order button on the Work Orders page](/images/rtaImage-313.jpg "The Create Work Order button on the Work Orders page")
    </Frame>
  </Step>
  <Step title="Choose the property." icon="2" iconType="sharp-solid" stepNumber={2} titleSize="h4">
    Under **Assign a Property**, choose how you'd like to search: **Search by Resident Phone Number** or **Search by Property Address**. This guide uses the property address.

    <Frame>
      ![Search options for assigning a property](/images/rtaImage-314.jpg "Search options for assigning a property")
    </Frame>

    Type the address in the search bar, then select the property from the results.

    <Frame>
      ![Property address search results](/images/rtaImage-315.jpg "Property address search results")
    </Frame>
  </Step>
  <Step title="Confirm it's a new issue." icon="3" iconType="sharp-solid" stepNumber={3} titleSize="h4">
    If the property already has an open work order, a pop-up lets you know. If this is a different issue, click **Yes, this is a new issue**.

    <Frame>
      ![Pop-up about an existing work order at the property](/images/rtaImage-316.jpg "Pop-up about an existing work order at the property")
    </Frame>
  </Step>
  <Step title="Choose the resident." icon="4" iconType="sharp-solid" stepNumber={4} titleSize="h4">
    Select the resident for this work order, or mark the property as vacant.

    <Frame>
      ![Selecting a resident or marking the property as vacant](/images/rtaImage-317.jpg "Selecting a resident or marking the property as vacant")
    </Frame>
  </Step>
  <Step title="Fill in the Basic Details." icon="5" iconType="sharp-solid" stepNumber={5} titleSize="h4">
    Add the main details of the job, then click **Next Step**.

    - **Work Order Name:** What the work order will be called.
    - **Work Order Number:** Optional. Latchel creates one automatically, so only add your own if you prefer a specific number.
    - **Description:** What the problem is and what needs to be fixed. This is written for the service provider.
    - **Max Budget:** Your budget estimate for the job.
    - **Skill Required:** The skill needed to fix the problem, if you know it. Not sure? Click **Ask Resident to identify issue** instead (see the tip below).

    <Frame>
      ![The Basic Details step of a new work order](/images/rtaImage-318.jpg "The Basic Details step of a new work order")
    </Frame>

    <Frame>
      ![Choosing the skill required and max budget](/images/rtaImage-319.jpg "Choosing the skill required and max budget")
    </Frame>

    <Frame>
      ![Basic Details filled in with a skill and max budget](/images/rtaImage-320.jpg "Basic Details filled in with a skill and max budget")
    </Frame>
  </Step>
  <Step title="Add the Additional Details." icon="6" iconType="sharp-solid" stepNumber={6} titleSize="h4">
    Fill in anything else the job needs, then click **Next Step**.

    - **Update Resident Availability:** When the resident is available for a technician visit, if you know.
    - **Can resident cancel this work order:** Whether the resident is allowed to cancel it.
    - **Does the service provider have permission to enter if the resident is not present:** Yes or no.
    - **Assign a Service Provider manually:** Choose the service provider for this job right here, while you create the work order. There's no need to open the work order again afterward to add one. If you'd rather not pick one, Latchel's auto-assignment setup takes over.
    - **Do you have any files related to the work order:** Add a photo or short video that shows the problem.
    - **Instruction to Service Provider:** Anything the service provider should know before or during the visit.

    {/* TODO: screenshot of the updated work order creation flow showing the service provider field */}

    <Frame>
      ![The Additional Details step of a new work order](/images/rtaImage-321.jpg "The Additional Details step of a new work order")
    </Frame>
  </Step>
  <Step title="Review and submit." icon="7" iconType="sharp-solid" stepNumber={7} titleSize="h4">
    On **Review and Submit**, check everything you entered. Need to change something? Hover over the tracker on the side to jump back to any section. The caret shows which step you're on, and a filled-in circle means that step is complete.

    <Frame>
      ![The Review and Submit step with the side tracker](/images/rtaImage-322.jpg "The Review and Submit step with the side tracker")
    </Frame>

    When everything looks good, click **Submit Work Order**. Latchel starts working on it right away.
  </Step>
</Steps>

### **Things to Remember**

<Tip>
  **Not sure what skill the job needs?** Click **Ask Resident to identify issue**. We'll send the resident a notification to complete the diagnostic questions, and once they do, Latchel starts working on the work order automatically.
</Tip>

<Tip>
  **Is this a job that repeats?** When you create a work order, you can select **Repeat this work order on a schedule** to make it recurring. See [How to Submit and Manage Recurring Work Orders](/s/topic/0TO5e000000h9wqGAA/how-to-submit-and-manage-recurring-work-orders).
</Tip>

### **Frequently Asked Questions**

<AccordionGroup>
  <Accordion title="Can I choose the service provider while I create the work order?">
    Yes. In the **Additional Details** step, use **Assign a Service Provider manually** to pick one. If you leave it blank, Latchel's auto-assignment setup takes over.
  </Accordion>

  <Accordion title="Do I need to add a work order number?">
    No. Latchel creates a work order number automatically. Only add one if you prefer your own.
  </Accordion>

  <Accordion title="Can I go back and change something before I submit?">
    Yes. On the **Review and Submit** step, hover over the tracker on the side to jump back to any section and edit it.
  </Accordion>

  <Accordion title="Can I create a work order for a vacant property?">
    Yes. When you choose the resident, mark the property as vacant instead.
  </Accordion>
</AccordionGroup>
