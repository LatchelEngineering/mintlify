title: "Yardi Voyager Standard Interfaces Setup"
description: "This help guide will provide you with the basic steps to set up your **Yardi Voyager interface with Latchel**. As an approved Yardi standard interfaces vendor, Latchel ensures that your property and resident data are always up-to-date, making your service requests seamless and organized."
---

<Warning>
  Before proceeding, it is critically important that the steps are conducted in the order defined below. Going out of order could cause syncing issues with your data in Latchel and/or Yardi.
</Warning>

## **Step 1 - Configuring the Vendor Options for Latchel**

<Check>
  **Menu Path:** Basic iData Menu \> Interfaces \> Configuration \> Review Interface Vendors \> Interface Configuration
</Check>

<Steps>
  <Step title="**Confirm the vendor name appears**" icon="1" iconType="sharp-solid" stepNumber={1} titleSize="p">
    **Confirm the vendor name appears in Voyager** under the appropriate Interface configuration. If vendor is not present, contact Yardi Technical Support to load the vendor package.
  </Step>
  <Step title="**Select the vendor name**" icon="2" iconType="sharp-solid" stepNumber={2} titleSize="p">
    Select the **vendor name**.
  </Step>
  <Step title="**Select the configuration options**" icon="3" iconType="sharp-solid" stepNumber={3} titleSize="p">
    Select the **options desired on the vendor configuration screen**. These options are based on client preferences and vendor requirements. The available options vary depending on the interface type.
  </Step>
  <Step title="**Save the configuration**" icon="4" iconType="sharp-solid" stepNumber={4} titleSize="p">
    **Save** the configuration options.
  </Step>
</Steps>

## **Step 2 - Configure the Property or Property List**

<Check>
  **<u>For a Single Property:</u>**

  **Menu Path:** Setup \> Property \> Find Property \> [property code] \> Submit
</Check>

<Steps>
  <Step title="**Open Interface Configuration**" icon="1" iconType="sharp-solid" stepNumber={1} titleSize="p">
    Click on **Functions** drop down menu. Click on **Interface Configuration**.
  </Step>
  <Step title="**Click the interface type**" icon="2" iconType="sharp-solid" stepNumber={2} titleSize="p">
    Click the appropriate **Interface type** under Interface Configuration (i.e. Vendor Invoicing).
  </Step>
  <Step title="**Select Latchel and save**" icon="3" iconType="sharp-solid" stepNumber={3} titleSize="p">
    **Highlight Latchel** under Available Agencies. Click **Select** and **Save**.
  </Step>
</Steps>

<Check>
  **<u>For a Property List:</u>**

  **Menu Path:** Interfaces \> Configuration \> Bulk Property Configuration
</Check>

<Steps>
  <Step title="**Enter the property list code**" icon="1" iconType="sharp-solid" stepNumber={1} titleSize="p">
    Enter **property list** **code**.
  </Step>
  <Step title="**Select the interface type**" icon="2" iconType="sharp-solid" stepNumber={2} titleSize="p">
    Select **Interface Type** from drop down.
  </Step>
  <Step title="**Select Configure**" icon="3" iconType="sharp-solid" stepNumber={3} titleSize="p">
    Select **Configure**.
  </Step>
  <Step title="**Select Latchel and save**" icon="4" iconType="sharp-solid" stepNumber={4} titleSize="p">
    **Highlight Latchel** from list of Available Agencies and click **Save**.
  </Step>
</Steps>

## **Step 3 - Configure the Interface User**

<Check>
  **Menu Path:** System Administration \>Security \> Add User
</Check>

<Steps>
  <Step title="**Create a new interface user**" icon="1" iconType="sharp-solid" stepNumber={1} titleSize="p">
    Create a **new interface user** and link to a security group for the specific Interface Type. The security group should have **Read or Read/Write access** for appropriate web services permission(s). (e.g. Interfaces: Web Service – Common Data)
  </Step>
  <Step title="**Enter the property code**" icon="2" iconType="sharp-solid" stepNumber={2} titleSize="p">
    Enter the **property code** or **property list code** in the property field to allow interface user access to properties configured for Latchel.
  </Step>
  <Step title="**Select Interface User privileges**" icon="3" iconType="sharp-solid" stepNumber={3} titleSize="p">
    Click on **Privileges** tab and select **Interface User**. This will give user access through the web services, but not the Voyager front end.
  </Step>
  <Step title="**Click Save**" icon="4" iconType="sharp-solid" stepNumber={4} titleSize="p">
    Click **Save**.
  </Step>
</Steps>

## **Step 4 - Provide Access Information to Latchel**

<Steps>
  <Step title="**Share the Voyager URL**" icon="1" iconType="sharp-solid" stepNumber={1} titleSize="p">
    Voyager URL (vendor will append the appropriate web services endpoint).
  </Step>
  <Step title="**Share the interface username and password**" icon="2" iconType="sharp-solid" stepNumber={2} titleSize="p">
    Interface username and password.
  </Step>
  <Step title="**Share the database name**" icon="3" iconType="sharp-solid" stepNumber={3} titleSize="p">
    Database Name
  </Step>
  <Step title="**Share the server name**" icon="4" iconType="sharp-solid" stepNumber={4} titleSize="p">
    Server Name (will always be the same as Database Name)
  </Step>
</Steps>

<Note>
  You should always notify the third-party vendor of any changes to Voyager URL, database server or database name.
</Note>

## **Which Residents Sync From Yardi**

Once your interface is set up, Latchel brings your residents over from Yardi, including roommates and other adult occupants. That way everyone living in the unit can get help, not just the lease holder.

- **Roommates, spouses, and other adult occupants** each get their own resident record in Latchel, with their own name, phone number, and email. They can verify into the resident dashboard and submit work orders.
- **Work orders from a roommate** go to Yardi filed under the lease, the same as one from the lease holder.

<Note>
  Some people listed in Yardi don't sync as residents:

  - **Guarantors, co-signers, and emergency contacts.** They don't live in the unit, so they don't get resident access.
  - **Minors.** An occupant is skipped if Yardi marks them as a Child or Dependent, or if their **Occupant Type** field says anything other than Adult. A blank **Occupant Type** counts as an adult, since Yardi leaves it blank for most people.
</Note>

## **Compatibility Requirements**

To use Latchel as a Yardi standard interfaces vendor, customers **must have Voyager 7S** with the following **minimum plug-in versions**:

- Interfaces PIv22
- Common Data PIv19
- Service Requests PIv15

If you have an earlier plug-in version, enter a support ticket to your Yardi Account Manager or team to request the vendor package for Latchel to be loaded to your database. This will make Latchel appear in your Yardi Voyager environment for configuration.

<Tip>
  For other questions about compatibility, and/or if assistance is needed with any step in this help article, please enter a support ticket to your Yardi Account Manager or team.
</Tip>
