Skills decide which work orders an SP can be assigned to. There are two places to update them, and they do different things, so make sure you're changing the right one.

| Where | What it changes |
| --- | --- |
| **SP profile** | Everything the SP can do, across all PMs |
| **PM's priority list** | Which of the SP's skills this PM uses them for. The SP's profile doesn't change. |

### **How to Update Skills on the SP's Profile**

<Steps>
  <Step title="Open the SP's profile." icon="1" iconType="sharp-solid" stepNumber={1} titleSize="h4">
    Go to **People > Service Providers** and open the SP. The skills list is the second section of the **Details** tab.
  </Step>
  <Step title="Click + Add Skills." icon="2" iconType="sharp-solid" stepNumber={2} titleSize="h4">
    Choose a category, then check or uncheck skills. Use **Check all** or **Uncheck all** to change a whole category.

    For handymen and general contractors, use **+ Add Quick Create Skill Set** instead and choose **Handyman Skills**, **General Contractor**, or **All Skills/All Trades**.
  </Step>
  <Step title="Click Save." icon="3" iconType="sharp-solid" stepNumber={3} titleSize="h4">
    The SP can now be added to those skill categories on any PM's priority list.
  </Step>
</Steps>

### **How to Update Skills on a PM's Priority List**

<Steps>
  <Step title="Open the priority list." icon="1" iconType="sharp-solid" stepNumber={1} titleSize="h4">
    Go to the PM's **Categories & Priorities** at the company, portfolio, or property level.
  </Step>
  <Step title="Click the three dots next to the SP and choose Edit Skills." icon="2" iconType="sharp-solid" stepNumber={2} titleSize="h4">
    Check the skills this PM should use the SP for, and uncheck the rest.
  </Step>
  <Step title="Click Save." icon="3" iconType="sharp-solid" stepNumber={3} titleSize="h4">
    Only this PM's priority list changes.
  </Step>
</Steps>

### **Things to Remember**

<Note>
  An SP only shows up for a skill on a PM's list if that skill is on their profile first. If you can't select a skill on the priority list, add it to the SP's profile.
</Note>

<Tip>
  Use query **V18** to see each SP's categories and skills before and after your update.
</Tip>
