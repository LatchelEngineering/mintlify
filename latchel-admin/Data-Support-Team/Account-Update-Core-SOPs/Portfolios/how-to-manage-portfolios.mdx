Portfolios group a PM's properties so they can share settings, such as the assigned PM user, owner, service provider prioritization, budget limits, and emergency contacts. Settings flow from **Company > Portfolio > Property**, so putting a property in the right portfolio gives it the right setup automatically.

<Check>
  **In other words:**

  Moving a property into a portfolio changes the settings it inherits. Always check what the portfolio will pass down before you assign properties to it.
</Check>

### **Common Portfolio Requests**

Portfolio requests come through the **Account Update Request** Typeform under **Portfolios**:

- Create new portfolios
- Add and remove properties
- Assign an owner
- Manage service providers (see [How to Manage Service Providers](/latchel-admin/Data-Support-Team/Account-Update-Core-SOPs/Service-Providers/how-to-manage-service-providers))
- Remove portfolios for off-boarded owners

### **How to Create a Portfolio**

<Steps>
  <Step title="Impersonate the PM." icon="1" iconType="sharp-solid" stepNumber={1} titleSize="h4">
    In app.latchel.com, impersonate a user from the PM company.
  </Step>
  <Step title="Go to Places > Portfolios and click New Portfolio." icon="2" iconType="sharp-solid" stepNumber={2} titleSize="h4">
    Enter the portfolio name exactly as the PM wrote it in their request.
  </Step>
  <Step title="Choose the assigned property manager, if requested." icon="3" iconType="sharp-solid" stepNumber={3} titleSize="h4">
    This is optional. You can change it later from the portfolio's **Details** tab.
  </Step>
  <Step title="Click Create." icon="4" iconType="sharp-solid" stepNumber={4} titleSize="h4">
    Open the new portfolio and note the portfolio ID at the end of its URL. You'll need it for bulk assignments.
  </Step>
  <Step title="Set up the portfolio's details." icon="5" iconType="sharp-solid" stepNumber={5} titleSize="h4">
    On the **Details** tab, add the owner, emergency escalation contacts, and any other settings in the request.
  </Step>
</Steps>

### **Things to Remember**

<Note>
  Assign owners at the portfolio level, not the property level, so every property in the portfolio gets the same owner.
</Note>

<Tip>
  The PM's portfolio groups often come from their PMS, such as the **Property Group** field in AppFolio. Ask for the PM's file or PMS access if the request doesn't say which properties go where.
</Tip>
