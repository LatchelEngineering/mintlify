## 🧠 What This Process Is Trying to Solve

<Info>
  We want to assist owners with submitting work orders directly. The goal is to verify owner status, gather all relevant information, and create the work order in real time, ensuring issues are handled quickly and accurately while reducing delays, miscommunication, and frustration for both owners and property managers.
</Info>

## 📋 Step-by-Step Process

### Step 1 - **Verify Owner Status**

1. **Check if the owner is registered** in the property profile ([<u>(TECH 101) How to: Navigate Properties Tab in the Latchel Console | Details Tab</u>](https://latchel.atlassian.net/wiki/spaces/OPS/pages/464388136/How+to+Navigate+Properties+Tab+in+the+Latchel+Console)).
2. **If registered:** Proceed to Step 2
3. **If not registered:**
4. Ask for the **_property address_**
5. **Say something like:** “_Thank you for reaching out. In order for us to create a new work order, we’ll need to verify the property address where the issue is occurring. Could you please provide the full property address? Once we have that, we’ll be able to move forward with submitting the request._”
6. If they can provide the property address, proceed as with registered owners, but note that some updates may go to the PM or resident on file.
7. **NOTE**: When submitting the WO,  submit it following the process for a **Requesting maintenance at a home they do not live in**
8. **Say something like:** _"Thank you for reaching out about [issue]. I’ll go ahead and create the work order in our system. Since you’re not listed as the registered owner, some updates may go directly to the property manager or resident on file. If approval is needed, we’ll reach out to the registered PM or primary owner before moving forward."_
9. If they are unable to provide the property address, let the Owner know we will need a property address to be able to submit a work order
10. **Say something like**: “_I completely understand. Unfortunately, we aren’t able to submit a work order without the property address, since it’s required to ensure the request is sent to the correct property manager and team. If you’re able to locate the address later, please text us back and we'll be happy to assist right away.”_
11. **If the property address the owner is calling about is NOT in the system**, proceed with submitting the work order through the **“Caller is a Resident”** path.
12. Refer to Step 4.b in [(TECH 101) How to: Create a New Work Order from "Incognito Mode" (All Submissions)](https://latchel.atlassian.net/wiki/spaces/OPS/pages/781647909/How+to+Create+a+New+Work+Order+from+Incognito+Mode+All+Submissions+)
13. When creating the WO, the associate must clearly note in the description that **the owner called on behalf of the resident and reported the issue**.

2. For the emergency admin team member handling the Need to Verify email, refer to **_question #3_** [How to: Handle "Need to Verify" Emails](https://latchel.atlassian.net/wiki/spaces/OPS/pages/768999793/How+to+Handle+Need+to+Verify+Emails)
3. If the PM company is inactive, do not proceed. Advise the owner to contact their management company directly.

### Step 2- **Gather relevant information**

1. Acknowledge the request and confirm receipt.
   1. **Say something like:** _"Hi [Owner’s Name], thanks for reaching out about [issue, e.g., the plumbing leak]. Let’s get a few details so I can open a work order and make sure it’s handled quickly for you."_
2. Ask if the owner prefers to continue by text (through **Conversations**) or would like a call (**_only call if requested_**).
3. Inform the owner that you will ask a series of diagnostic questions. Gather required details (issue, location, urgency, access), asking/sending questions one at a time.
   1. _Important:_ While communicating with the Owner, ensure that you are creating the work order in real time. This allows you to ask the correct diagnostic questions as you proceed.
4. **Text messages (Conversations):** Owner texts go through the **Conversations** icon. Latchel AI does not answer Owners, so these threads come to staff. Check that no one else is typing, then click **Mark as Handled** before replying:
   1. If the Owner is **responsive**, continue the conversation by text in **Conversations** until all necessary information has been collected.
   2. If the Owner is **unresponsive for 3 minutes, send them another message:**
      1. **Say something like:** _“Hi [Owner], we haven’t heard back in a bit. If there’s no response, we’ll go ahead and close this request for now. You can always text us back when you’re ready._
5. There is no End Conversation option in **Conversations**, so leave the thread as is.
6. Proceed to Step 3

### Step 3 - **Create the Work Order**

1. Create the work order in the system with all gathered details.
2. Confirm work order creation with the owner and send them a text through **Conversations** including the work order number and next steps.
3. **Say something like:** _"Perfect, thank you for the details. I’ve now created the work order in our system. The work order number is [work order number], and [provide the next steps based on the status of the work order]. Is there anything else I can assist you with today?”_

## 🎯 When to Break This SOP

- **Do not break or deviate from this SOP on your own authority.** Always escalate to an Ops Support specialist or follow explicit instructions if you believe an exception is necessary.
