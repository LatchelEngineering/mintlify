## 🧠 What This Process Is Trying to Solve

We want to ensure that associates can accurately determine whether a Property Management Company is on an active integration with Latchel. The goal of this SOP is to provide clear, step-by-step instructions for verifying integration status before proceeding with work orders or property updates.

## 📋 Step-by-Step Process

### Check if a Property Management Company is on Active Integration

Click "Start Tutorial" to start watching.

### PMs with Active Integration

1. Chrome Plugin - also known as "Latchel Data Sync Extension". Proceed to advise the PM to run their sync and provide them with the available help guide [here](https://help.latchel.com/s/article/Latchel-Data-Sync-Extension-Reference-Guide).

2. Other Integrations or Property/Resident Restricted Customers (API/Webhook, Propertyware, Buildium, Rent Manager, Yardi, Rentredi).

   Escalate to Product Support. Refer to [How to: Escalate to Product Support](https://help.latchel.com/latchel-admin/Service-Operations/Production-Documentation/How-to-Escalate-to-Product-Support#how-to-escalate-to-product-support).

### PMs with No Active Integration

1. Manually add the property address
2. Provide the PM the guides to add the [property](https://help.latchel.com/s/topic/0TO5e000000h9wqGAA/How-to-Add-a-Property#how-to-add-a-property)/[resident](https://help.latchel.com/s/topic/0TO5e000000h9wqGAA/How-to-Add-Manage-Residents#how-to-add-and-manage-residents).
3. Proceed to create the work order.

### PMs with Active Integration but "Paused"

Go to the PM Profile's Integrations' tab.

**Step 1.** Escalate to the Operations Support Specialists so they can check the following settings.

1. Go to the "Details" page. Under "Miscellaneous Settings", check the "Property Modification" and "Resident Modification" settings.
2. **Toggle Position – Left:** This indicates that the action is allowed, which may imply that the integration is no longer active.
   - Property or Resident Modification: If the property or resident is not in the system, add their details to allow the work order to proceed.
   - The Operations Support Specialist will update the associate on the current settings and advise on the next action to take based on the above before the NTV email is sent to the Property Manager.
   - Refer to [How to: Handle "Need to Verify" Emails](https://help.latchel.com/latchel-admin/Service-Operations/Production-Documentation/How-to-Handle-Need-to-Verify-Emails#how-to-handle-need-to-verify-emails) for the appropriate steps once the settings is verified.
3. **Toggle Position – Right:** This requires escalation to Product Support. Refer to [How to: Escalate to Product Support](https://help.latchel.com/latchel-admin/Service-Operations/Production-Documentation/How-to-Escalate-to-Product-Support).
