## 🧠 What This Process Is Trying to Solve

<Note>
  We want to prevent missed, delayed or duplicated replies to **Property Manager web chats** in the Latchel Console. This page shows you how to open, reply to, tag and close a PM web chat in the legacy SMS icon, and how to spot (and report) anything that shows up there by mistake.
</Note>

<Warning>
  🔔 **What this page covers and what it doesn't**

  | Message type | Where you work it | Follow |
  | --- | --- | --- |
  | **PM web chats** (PMs write to us from their Latchel Support icon) | Legacy **SMS icon** (chat bubble) in the Latchel Console | This page |
  | **Text messages** from Residents, Service Providers, Property Managers and Owners | **Conversations** icon (**Team** and **My messages** views) | [Job Aid: Handling AI Messaging - Conversations](/latchel-admin/Service-Operations/Production-Documentation/Job-Aid-Handling-Resident-and-SP-Conversations-AI-Messaging-Beta) |

  - In Conversations, Latchel AI answers residents and SPs first (where it is active) and hands off to staff. Threads are tagged automatically, you claim them with **Mark as Handled**, and there is no assigning or End Conversation. None of the steps on this page apply there. See [What a Latchel AI Handoff Looks Like](/latchel-admin/Service-Operations/Production-Documentation/Job-Aid-Handling-Resident-and-SP-Conversations-AI-Messaging-Beta#what-a-latchel-ai-handoff-looks-like).
  - Owners don't have dashboard access, so they have no web chat. Texts to and from Owners are in Conversations.
  - If a resident, SP or Owner message appears in the SMS icon, report it in #bug-report.
  - Both icons have **equal priority**. Always work the **oldest** unhandled message first by timestamp, across both icons.
</Warning>

  **Training Content**

## 💬 About PM Web Chat

<Accordion title="About PM web chat">
  1. <u>What is PM web chat?</u>
     1. PM web chat is how Operations team members chat with Property Managers from the Latchel Console. You work it in the legacy SMS icon. PMs see it as their Latchel Support icon, next to their Conversations icon.
  2. <u>Who can I web chat with?</u>
     1. Property Managers only. To text a Resident, Service Provider, Property Manager or Owner, use Conversations (WO → **Conversations** tab → **Open Conversation**, or the **Message** option on their profile). See [Sending Outbound Messages](/latchel-admin/Service-Operations/Production-Documentation/Job-Aid-Handling-Resident-and-SP-Conversations-AI-Messaging-Beta#sending-outbound-messages).
     2. Refer to [Job-Aid: Guide to write SMS/Webchat or email to customers](/latchel-admin/Service-Operations/Production-Documentation/Job-Aid-Guide-to-write-SMS-Webchat-or-email-to-customers) for writing guidance.
</Accordion>

## 📋 Step-by-Step Process

### Step 1: How to Identify the Property Manager

<Expandable title="How to identify the Property Manager">
  1. When the sender's name is known, the chat header shows their name.
     1. Click the name to open their profile.
  2. Check the letter in parentheses before the name. PM web chats should show **(PM)**.

  <Frame>
    ![](/images/SVC-366.png)
  </Frame>

  3. If the chat shows a Resident **(R)** or Service Provider / Vendor **(V)**, it belongs in Conversations. Report it in #bug-report.
</Expandable>

### Step 2: How to Open an Incoming Web Chat

1. Click the chat bubble (SMS) icon with the red circle containing a number.
2. Click **Pending Messages** to open the inbound web chats sent to Latchel.

<Frame>
  ![](/images/SVC-367.png)
</Frame>

<Frame>
  ![](/images/SVC-368.png)
</Frame>

<Frame>
  ![](/images/SVC-369.png)
</Frame>

3. The number in the circle shows how many chats in the General Queue have not been assigned. These are "New" messages.
4. Before you open one, compare timestamps with **Conversations → Team** and take the oldest unhandled message first.
5. Review the past messages in the chat.
6. Use [How to: Handle Conversations/Webchat](/latchel-admin/Service-Operations/Production-Documentation/How-to-Handle-SMS-Webchat-Contacts-New-Support-Framework) and the [(PREMIUM) Job Aid: Phone and Text Message/Webchat Frequently Asked Questions](/latchel-admin/Service-Operations/Production-Documentation/PREMIUM-Job-Aid-Phone-and-Text-Message-Webchat-Frequently-Asked-Questions-Live-Updates) to resolve or advance the request within your job duties.

### Step 3: How to Assign the Web Chat to Yourself

<Note>
  ### Another User Is Responding

  While another user is actively responding to a chat, all users see "[username] is typing...". This prevents two people from handling the same chat. If you see it, move on to another message.

  If you need to reach another user who is (mistakenly) handling the same chat, use Slack and the guidelines in your team's internal communication policy.
</Note>

1. Sending a reply in the chat assigns it to you. No other action is needed.
   1. **_Why?_** It keeps team members from overlapping on the same chat.
2. Reply with the answer or next step, following [How to: Handle Conversations/Webchat](/latchel-admin/Service-Operations/Production-Documentation/How-to-Handle-SMS-Webchat-Contacts-New-Support-Framework). If the PM hasn't said what they need, ask how you can help. If you need time to research, tell the PM you're taking a moment to gather information.
3. If you can't handle the chat to completion, go to Step 4.

### Step 4: How to Escalate a Web Chat to a Peer or Supervisor

1. Refer to [How to: Escalate Between Teams](/latchel-admin/Service-Operations/Production-Documentation/How-to-Escalate-Between-Teams)
2. Write effective notes: [How to: Write Effective Notes](/latchel-admin/Service-Operations/Production-Documentation/How-to-Write-Effective-Notes)

### Step 5: How to Close the Text Message

<Warning>
  🛑 NOTE: This step applies to PM web chat only. Conversations have no tagging, End Conversation or Close Window step. Click **Mark as Handled** instead (see [Handling Inbound Messages](/latchel-admin/Service-Operations/Production-Documentation/Job-Aid-Handling-Resident-and-SP-Conversations-AI-Messaging-Beta#handling-inbound-messages)).
</Warning>

1. Before closing, send the wrap-up and CSAT survey messages per [Final Assurance and Engagement](/latchel-admin/Service-Operations/Production-Documentation/How-to-Handle-SMS-Webchat-Contacts-New-Support-Framework#🤝final-assurance-and-engagement). If the PM hasn't replied 3 minutes after your latest message, follow [Handling Unresponsive or Upset Client](/latchel-admin/Service-Operations/Production-Documentation/How-to-Handle-SMS-Webchat-Contacts-New-Support-Framework#❗handling-unresponsive-or-upset-client).
2. Tag the chat to the appropriate Work Order or Property Manager company.
   1. Refer to [Updated SMS Tagging Designs for Ops](https://help.latchel.com/latchel-admin/Product-Engineering/updated-sms-tagging-designs-for-ops#updated-sms-tagging-designs-for-ops) for how the tagging feature works.
   2. Tag per this hierarchy:
      1. First, to a Work Order(s). This is the most common case.
      2. Second, to the Property Manager's company if the chat does not belong to a WO.
      3. Third, leave it untagged only if the chat truly does not belong to a WO or Property Manager company.
   3. If the chat is already tagged, verify that the tag is correct. If it's incorrect, remove it and tag it correctly.
   4. **Important:** All PM web chats need to be tagged properly before you end them.
3. From the open chat, click the three dots on the right-hand side to **End Conversation** or **Close Window**.

   1. If you transfer the chat to someone else, it disappears from your Latchel Console once it has been assigned to them. That means the transfer worked.
   2. **<u>"End Conversation"</u>**: Click this when you've finished all work on the chat (including your notes), even if you're still waiting on a reply. It unassigns you.
      1. **IMPORTANT**: Never end a chat if the request is not fully addressed. If you are transferring the chat to someone else, do NOT use this option.
   3. **<u>"Close Window"</u>**: Click this to close the chat window but keep it active. The chat stays assigned to you so you can return to it later.
      1. When the PM responds, the messages are forwarded to you.
4. You don't need to log the chat manually. PM web chat transcripts are logged automatically. If you updated the work order because of the chat, leave a WO note explaining the action and why, following [How to: Write Effective Notes](/latchel-admin/Service-Operations/Production-Documentation/How-to-Write-Effective-Notes).
