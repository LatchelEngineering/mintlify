Use this page to find the right guide or process when a PM asks us to change something in their account. For the most common customer help guides, see the [Help Center Reference Guide](/latchel-admin/Service-Operations/Production-Documentation/Help-Center-Reference-Guide).

<Warning>
  **Check the account setup before you change anything.** Many settings can be set at the company, portfolio or property level. Review how the PM's account is set up and read [Configuration Inheritance (Property, Portfolio & Company Level)](/s/topic/0TO5e000000h9wqGAA/Configuration-Inheritance-Property-Portfolio-Company-Level) so you update the right level.
</Warning>

## Intake, emergencies and escalations

<Info>
  **Intake Settings (Harmonia) replaced Severity/Responsibility Settings and Emergency Temperature Settings.** Harmonia X replaced the point-and-click diagnostic flow. PMs now control how work orders are classified, and which questions residents are asked, through their intake rules.
</Info>

| **Request** | **Where to go** |
| :-- | :-- |
| Emergency definitions, or how work orders are classified (formerly "severity settings") | <ul><li>[Introduction to Intake Settings](/s/topic/0TO5e000000h9wqGAA/Introduction-to-Intake-Settings)</li><li>[Managing Intake Settings](/s/topic/0TO5e000000h9wqGAA/Managing-Intake-Settings)</li><li>[Service Ops: Handling Work Order Severity via Harmonia/Harmonia X Intake Settings](/latchel-admin/Service-Operations/Production-Documentation/Service-Ops-Handling-Work-Order-Severity-via-Harmonia-Harmonia-X-Intake-Settings)</li><li>PM feedback on how a specific work order was classified: submit it from the work order's **Intake Details** (thumbs up or down). See [Job Aid: Slack Channels & Escalation Workflows](/latchel-admin/Product-Support-Team/Job-Aid-Slack-Channels-Escalation-Workflows).</li></ul> |
| Changing the questions residents are asked during intake (formerly "diagnostic flow questions") | <ul><li>Questions are generated from the PM's Intake Settings, so start with [Managing Intake Settings](/s/topic/0TO5e000000h9wqGAA/Managing-Intake-Settings).</li><li>If the PM needs something Intake Settings can't do, log it as a feature request. See [How to Handle: Feature Requests](/latchel-admin/Product-Support-Team/How-to-Handle-Feature-Requests).</li></ul> |
| Changing on-call or contact rotation settings | <ul><li>[Job Aid: On-Call URLs (Intake Outcome vs. Contact Rotation)](/latchel-admin/Product-Support-Team/Job-Aid-On-Call-URLs-Intake-Outcome-vs-Contact-Rotation)</li><li>[Contact Rotation: Getting Started](/s/topic/0TO5e000000h9wqGAA/on-call-rotation-getting-started)</li><li>[How to Set Up a Contact Rotation](/s/topic/0TO5e000000h9wqGAA/How-to-Set-up-an-On-Call-Rotation)</li><li>[Setting Up Absences](/s/topic/0TO5e000000h9wqGAA/setting-up-absences)</li></ul> |
| Escalation preferences (for example, we're calling the wrong PM for this property) | <ul><li>[Emergency & Escalation Settings](/s/topic/0TO5e000000h9wqGAA/Emergency-Escalation-Settings-Overview)</li><li>Emergency Escalation Contacts follow configuration inheritance. Check the company, portfolio and property levels: [Configuration Inheritance](/s/topic/0TO5e000000h9wqGAA/Configuration-Inheritance-Property-Portfolio-Company-Level).</li><li>If the escalation contacts field uses a contact rotation URL, see [Job Aid: On-Call URLs](/latchel-admin/Product-Support-Team/Job-Aid-On-Call-URLs-Intake-Outcome-vs-Contact-Rotation).</li></ul> |
