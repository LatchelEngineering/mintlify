## Purpose

<Note>
  **Purpose of this document**

  To give AppFolio customers a backup option when running the sync themselves isn't working: Latchel runs the Latchel Data Sync extension on the customer's behalf from our remote server (TeamViewer). Once set up, the PM shows as **Latchel-managed** on the [Integration Health dashboard](https://app.latchel.com/admin/integration-health).
</Note>

<Note>
  **Scope**

  - Applies to AppFolio customers only.
  - Offered when a PM's own sync isn't running (e.g., Failing/Silent on Integration Health with **Managed by: the PM's browser**) or the PM reports sync issues. A CSM may also collect the login during onboarding.
  - Does not replace existing troubleshooting or standard support processes. See [Job Aid: Integration Functionality, Troubleshooting, and Setup Steps](/latchel-admin/Product-Support-Team/Job-Aid-Integration-Functionality-Troubleshooting-and-Setup-Steps).
</Note>

<Note>
  **Responsibilities**

  - **Product Support (PS):**
    - Offer the backup sync option to the PM.
    - Guide the PM in creating the Latchel user in AppFolio.
    - When the login comes in: log it in the software login spreadsheet, create/activate the Latchel integration user, set up the PM on the remote server, and run the first sync.
    - Confirm completion with the PM and close the ticket.
  - **Data Support (DS):** Ongoing daily monitoring of Latchel-managed syncs on Integration Health, re-running syncs, and troubleshooting. DS escalates to PS in `#ps-escalation` if the PM needs to act.
  - **CSM:** Only if they receive the AppFolio login during onboarding, submit the **Latchel Sync Request** workflow in `#ps-escalation`. PS then completes Steps 4–8.
  - **Customer:** Create a Latchel user in AppFolio with the required permissions and reply once it's done.
</Note>

<Warning>
  **The [software login spreadsheet](https://docs.google.com/spreadsheets/d/16B1d5acwDRvx6w8BkSuL4_QAOZmcXKYwf5HFpMcwRdU/edit?gid=2017091315#gid=2017091315) is confidential.** Log credentials there only. Never paste passwords in Slack threads, tickets, or DMs.
</Warning>

## Step-by-Step Guide

#### Step 1 - Offer the Backup Sync Option

1. Check the PM's row on [Integration Health](https://app.latchel.com/admin/integration-health). If it's already tagged **Latchel-managed**, we already run their sync. Don't email the PM; DS handles it.
2. Check Wavelength for prior outreach so the PM isn't contacted twice.
3. Email the PM using the template below. Replace **[X time]** with the real time since the last sync, taken from **Last data seen** on Integration Health (e.g., "almost a year"), not a placeholder number of days.

<Accordion title="Template: Sync not running + offer to run it for them">
  Hi [PM Name],

  We noticed that your AppFolio integration hasn't synced in **[X time]**. While this may be temporary, we recommend reinitiating the sync to make sure your data continues flowing correctly.

  **To restart the sync:**

  1. Make sure you or someone on your team has downloaded and activated the [Latchel Data Sync extension](https://chromewebstore.google.com/detail/latchel-data-sync/cefobanegfgmcneibgdbcjbegnnoafob).
  2. Log in to your **AppFolio dashboard**.
  3. Locate the floating **Latchel logo** on the right-hand side of the screen.
  4. Hover over the logo to open the pop-up panel.
  5. Select **"Click Here"** to reinitiate the sync.

  For additional details, you can reference our [troubleshooting article here](https://help.latchel.com/s/topic/0TO5e000000h9wqGAA/How-to-Download-and-Activate-the-Latchel-Data-Sync).

  **Or, let Latchel handle your syncs for you!**

  If you'd rather not manage this process manually or run into this issue again, **our team can run the sync on your behalf going forward**.

  To get this set up, we'll just need a Latchel user created in AppFolio with access to:

  - View units
  - View residents
  - View, edit, and create work orders

  [Here is a step-by-step guide](https://docs.google.com/document/d/1z8aflT7uonxNBByl3UWhU21U-10fXkadK53mNoDu-Pc/edit?tab=t.0) to help you create the user account. Once that's set up, **just reply to this email and let us know**. We'll take it from there and manage the sync from our side moving forward.

  If you have any questions along the way, we're happy to help!

  Best,

  Latchel Support
</Accordion>

<Tip>
  - **Timing:** if a PM's sync has only been down overnight or over a weekend, give it until the next business day before reaching out.
  - **Follow-up:** if the PM doesn't respond, follow up once (and include the offer if your first email didn't). Still no response → escalate to their CSM with the **PS Escalate to CSM** workflow, including the ticket links.
  - **Team outreach pushes:** when several PMs are being contacted at once, claim each PM in the Slack thread before emailing so nobody double-sends.
</Tip>

#### Step 2 - Customer Creates the Latchel User in AppFolio

The PM follows [AppFolio User Creation - Latchel Integration Management](https://docs.google.com/document/d/1z8aflT7uonxNBByl3UWhU21U-10fXkadK53mNoDu-Pc/edit?tab=t.0). The user needs access to the five reports the sync uses (Property Directory, Property Group Directory, Tenant Directory, Unit Directory, Work Order) and view/edit/create access to work orders.

#### Step 3 - Confirm the Setup

1. [success@latchel.com](mailto:success@latchel.com) receives the AppFolio account activation email with instructions to set a permanent password. Set the password.
2. Reply to the PM confirming we received it and that we'll take it from here.

<Note>
  The AppFolio URL is in the account activation email sent to [success@latchel.com](mailto:success@latchel.com).

#### Step 4 - Log the Credentials

Add the PM to the [software login spreadsheet](https://docs.google.com/spreadsheets/d/16B1d5acwDRvx6w8BkSuL4_QAOZmcXKYwf5HFpMcwRdU/edit?gid=2017091315#gid=2017091315) (AppFolio tab): AppFolio URL, username, and password, and mark the PM as a Latchel-run sync.

#### Step 5 - Set Up the PM on the Remote Server

1. Connect to the remote server in **TeamViewer**. Check the devices tab to see if someone else is already connected.
2. Open the Chrome profiles menu (top-right icon) → **Add Chrome profile** → choose to stay signed out. Name it for the PM and give it a unique color. **One profile per PM**, so credentials never mix.
3. Sign in to AppFolio with the credentials from the software login spreadsheet and save the password in the profile.
   - **Two-factor code:** click **Send verification code**. The code goes to the **Latchel console messages** (Latchel console number). It expires in **10 minutes** and Ops closes these quickly, so have the console open and grab it right away. If the number shown isn't the Latchel console number, it's probably the PM's phone; the PM needs to update it or send you the code.
4. In **Reporting → Reports**, confirm the Latchel user can open all five required reports. If any are missing, ask the PM to grant access before continuing.

<Warning>
  The remote server is **only** for PMs whose sync Latchel runs. Never set up profiles or run syncs there for anyone else.
</Warning>

#### Step 6 - Create/Activate the Latchel Integration User and Install the Extension

1. **In the Latchel console**, create or activate the PM's **Latchel Integration** user:
   - If one exists but is inactive, activate it.
   - If not, add a new user named **Latchel Integration**, using the **Latchel console phone number** and the same email as the AppFolio login.
   - Confirm the password from the welcome email. Use a **different password** than the AppFolio login, and record it in the software login spreadsheet.
2. **In the PM's Chrome profile**, open a new tab and install the [Latchel Data Sync extension](https://chromewebstore.google.com/detail/latchel-data-sync/cefobanegfgmcneibgdbcjbegnnoafob) (**Add to Chrome**), then pin it from the extensions menu.
3. Log in to the extension with the Latchel Integration user, then refresh the AppFolio tab so the extension appears.

#### Step 7 - Run the First Sync and Close the Session

1. In the extension, choose **Sync data in both directions** and start the sync. Confirm the extension shows it's syncing correctly.
2. **Close the TeamViewer session using the X on the far right.** Never click the laptop-style icon inside the window; it disconnects the remote server and engineering has to restore it.

#### Step 8 - Flag as Latchel-Managed

1. Make sure the **Latchel-managed** setting is on for the PM's integration so Integration Health uses the right thresholds and DS picks it up in daily monitoring. If you can't change it, ask in `#integration-health`.
2. Post in `#integration-health` that Latchel is now running the sync for this PM.
3. After the next dashboard check, confirm the PM's row shows **Managed by: Latchel** and fresh **Last data seen**.

#### Step 9 - Close the Ticket

1. Let the PM know we're now running their sync.
2. Add the label **"Integration Set Up"** to the Wavelength ticket for tracking.
3. Update the status to **Closed No Workflow**.
