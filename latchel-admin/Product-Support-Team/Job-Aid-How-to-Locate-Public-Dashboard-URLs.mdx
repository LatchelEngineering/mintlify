<Note>
  A **Public Dashboard URL** is a unique link that takes a resident or service provider straight to their Latchel dashboard without a password. Use it when someone can't log in or needs a quick way to their dashboard.
</Note>

<Warning>
  Each URL gives direct access to that person's dashboard. Only send it to the person it belongs to, after you've confirmed their identity. See [Job Aid: Handling User Login Issues](/latchel-admin/Product-Support-Team/Job-Aid-Handling-User-Login-Issues).
</Warning>

## Resident Public Dashboard URL

From their dashboard, residents can check or update maintenance progress, submit new requests and access their benefits. See [Resident Dashboard Overview](/s/topic/0TO5e000000h9wrGAA/Resident-Dashboard-Overview).

**PMs can find this link themselves**, so you can send them the help guide: [How to Access and View a Resident Public Dashboard](/s/topic/0TO5e000000h9wqGAA/How-to-Access-and-View-a-Resident-Public-Dashboard).

**Steps:**

1. Go to **People → Residents** and open the resident.
2. On the **Details** tab, scroll to the **Miscellaneous** box.
3. Click the arrow to expand it.
4. Click **Copy** next to the Public Dashboard URL.

## Service Provider Public Dashboard URL

<Note>
  The SP dashboard link works the same way, but it's **admin only**. PMs can't see it for their service providers, so only a Latchel admin can share it.
</Note>
