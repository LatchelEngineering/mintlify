<Note>
  **Who this is for:** new Product Support associates in their first week. Work through each section with your manager on Day 1. Our ticketing tool is **Wavelength (WL)**, formerly called Assembly. Ticket numbers still start with **ASM-** and links still go to `dashboard.askassembly.app`.
</Note>

## 1. Access you need

| Tool | What it's for | How to get access |
| --- | --- | --- |
| **Wavelength (WL)** | PS ticket queue (Product Support teamspace) | Manager adds you to the Product Support teamspace |
| **Slack** | Team chat, escalation workflows | Join the channels in section 2 |
| **Help Center (Mintlify)** | All SOPs and job aids: [help.latchel.com](https://help.latchel.com/latchel-admin/Product-Support-Team/product-support-overview) | Sign in with your @latchel.com Google account |
| **Latchel admin** | Work orders, properties, accounts, settings | Admin login on app.latchel.com |
| **Twilio** | Call and SMS logs for investigations | Manager requests access |
| **FullStory** | Session replays for investigations | Manager requests access |
| **PGAdmin** | Database lookups for investigations | Manager requests access |
| **Loom** | Recording walkthroughs for customers and the team | Sign in with Google |
| **Sheriff** | Shift schedule and time-off requests (replaced Deputy on Sep 21, 2026) | Sign in with Google |
| **Shared inbox** | [success@latchel.com](mailto:success@latchel.com) | Manager grants access |

<Warning>
  **Confluence is no longer used.** It isn't updated or managed. The Help Center (Mintlify) is the only source of truth for PS process. For process questions, use the **Mintlify assistant**, not Rovo, which still indexes the old Confluence library.
</Warning>

## 2. Slack channels

#### Owned and maintained by PS

| Channel | What it's for | Workflows in the channel |
| --- | --- | --- |
| **#ps-team-chat** | Private PS team channel | **PS Daily Check-In**, **DD Conclusion Workshop** (rewrite a DD conclusion into a PM-facing version), **FYI Heads Up PMs** (Friday reminder to flag PM tickets the CSM should know about, separate from tickets already escalated to the CSM) |
| **#psm-escalate** | Ask the PSM for help when you're stuck or unsure of next steps on a ticket | **PS Ticket Escalate** |
| **#ps-escalation** | Where Ops escalates to PS. Each submission creates a ticket in WL. | Ops escalation form, **Latchel Sync Request** (moved here Sep 16, 2026) |
| **#ps-dd-sddi** | Submit work orders for PS to deep dive | **DD Request** (delays, missed appointments, automation confusion, invoice disputes), **SDDI Request** (negative WO reviews, CSATs, Google Reviews) |
| **#pd_cn_actionset** | Pre-dispatch instructions, critical notes and action sets for review, approval and execution | **PD and CN Approval** (a PM, owner or SP wants an instruction or note added), **Action Set Request** |
| **#csm-escalations** | Tickets PS needs to hand to the CSM | **PS Escalate to CSM**. See [Product Support Team vs Customer Success Managers](/latchel-admin/Product-Support-Team/Product-Support-Team-vs-Customer-Success-Managers) |
| **#ps-cs-sync** | Private PS \<> CS channel for quick checks with a CSM, leadership advice or a heads-up. It doesn't replace #csm-escalations. | None |

#### Other channels PS uses

| Channel | What it's for |
| --- | --- |
| **#latchel-nomad** | Coordinating with NOMAD on owner cases |
| **#latchel-rentredi** | Coordinating with RentRedi on owner cases |
| **#accounts-receivable** | Subscription invoicing requests to AR |
| **#data-support-requests** | Account update requests for Data Support |
| **#data-reporting-help-requests** | Data and reporting requests that need custom queries |
| **#svc-ops-requests** | SOP and policy requests. To request a new SOP or a change to an existing one, use the **Ops SOP Requires Update** workflow and choose the **PS Mgmt** teamspace. A PS-specific SOP request workflow is coming soon. |
| **#svc-ops-feedback** | Operational feedback from other departments: praise, or complaints about unprofessional behavior (private) |
| **#integration-health** | Improving and refining processes for the [Integration Health Dashboard](https://app.latchel.com/admin/integration-health) |
| **#harmonia-feedback** | Good and bad feedback on Harmonia AI intake sessions and conversations, submitted by PMs and the Latchel team |
| **#partnerships-perks** | Questions about current partnerships and perks in the Resident Benefits Package (RBP) |
