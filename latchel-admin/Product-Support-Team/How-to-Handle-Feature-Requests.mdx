## New feature requests

### 1. Get the details

When a PM asks for a new feature, find out as much as you can:

- **The problem.** What's happening that led to the request? Focus on the problem, not just the solution. PMs often ask for a change without sharing the "why."
- **Their idea for a solution.** Solution ideas are useful, so capture them too.
- **Specific examples.** Work orders, email or SMS templates, screenshots, etc.

### 2. Check whether it can already be done

Some requests can be solved today without a new feature:

- **Action Sets:** see [Job Aid: Top PM Requested Action Sets](/latchel-admin/Product-Support-Team/Job-Aid-Top-PM-Requested-Action-Sets). New Action Sets go through the **Action Set Request** workflow in `#pd_cn_actionset`.
- **Pre-dispatch instructions or critical notes:** see [SOP: Pre-Dispatch Instructions & Critical Notes](/latchel-admin/Product-Support-Team/SOP-Pre-Dispatch-Instructions-Critical-Notes).
- **Intake rules:** see [Account Settings](/latchel-admin/Product-Support-Team/account-settings).

If one of these solves it, handle it that way instead.

### 3. Submit the request

1. Send the PM the **Feature Request for PM Experience** template in Wavelength.
2. Submit the request in `#feature-requests` using the **Feature Request** workflow.
3. Copy the Slack link and add it to the ticket as an internal note. See [SOP: Latchel Department Escalation Process](/latchel-admin/Product-Support-Team/SOP-Latchel-Department-Escalation-Process-for-Product-Support-Cases).
4. Close the ticket. The CSAT survey goes out **24 hours** after the ticket is closed.

## Follow-ups on existing requests

1. Send the PM the **Follow-Up on Feature Request** template in Wavelength.
2. If the PM pushes back or gets frustrated, escalate to the CSM. See [SOP: Escalating Tickets to the CSM](/latchel-admin/Product-Support-Team/SOP-Escalating-Tickets-to-the-CSM).

<Warning>
  **PM doesn't reply?** You don't need to send the Unresponsive Follow-Up template for feature requests. Close the ticket as unresponsive.
