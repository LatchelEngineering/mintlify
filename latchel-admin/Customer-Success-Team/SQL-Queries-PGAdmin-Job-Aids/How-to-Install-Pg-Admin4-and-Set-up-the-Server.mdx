# Objective

<Note>
### Purpose

The purpose of this document is to guide you through setting-up Pg\_Admin, which is a software used to run queries into our database and extract information. Once that is installed, you will need to add our server to connect the software with our database.
</Note>

# Content

**Step 1. Download Pg\_Admin4**

1.  Go to [https://www.pgadmin.org/download/](https://www.pgadmin.org/download/) 
    
2.  Click on the link to the Operating System you are using in your computer
        
          
          
        
3.  Click on the link to download the latest published version
        
          
          
        
4.  Click on the ".exe" (for Windows) ".dmg" (for Mac) file to download it to your computer

### **Step 2. Install Pg\_Admin4**

  

1.  Go to your "download" folder and open the file (double click on it) to start the install process. Follow the instructions in the screen and click on next to proceed.
        
          
          
        
2.  You will see a progress bar. When the installer has completed extracting all files, you will see the completion screen. Click on finish.
3.  Set your password
4.  After that, the software will open

### **Step 3. Set-up the Server**

  

1.  Click on "Add New Server
2.  If you don't have the credentials to our database yet, contact  to request it
    
3.  Create a name for this server. Enter Latchel Prod
4.  Click on the Connections tab to enter the server information and click on "save"
